## Рекомендации по изучению:

1. **Начните с простых задач (Easy)** для каждого алгоритма
2. **Прочитайте главу в книге**, затем решите соответствующие задачи
3. **Сначала решите без подглядывания**, потом изучите оптимальные решения
4. **Обращайте внимание на временную и пространственную сложность** - книга это хорошо объясняет
5. **Переходите к Medium задачам** только после уверенного решения Easy
